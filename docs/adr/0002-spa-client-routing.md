# Фронтенд — SPA с клиентской маршрутизацией (React Router)

Страницы приложения (главная, каталог типов встреч, дальше календарь и разделы владельца) — маршруты одного SPA на React Router, а не отдельные HTML-страницы Vite. Так страницы делят провайдеры, сгенерированный SDK и навигацию без перезагрузки. Следствие для деплоя: сервер, раздающий фронтенд, должен отвечать `index.html` на любой неизвестный путь, иначе прямой заход или обновление на `/book` даст 404.

## Considered Options

- Отдельные HTML-страницы Vite (multi-page): проще раздавать статикой, но общее состояние и навигацию пришлось бы собирать вручную.
- Без маршрутизатора, переключение экранов состоянием: нет адресов страниц, нельзя дать ссылку на каталог.
