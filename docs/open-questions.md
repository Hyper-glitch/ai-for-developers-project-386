# Открытые вопросы к карте следующего шага

Вопросы, которые всплыли при обсуждении главной страницы, но не решались на этом шаге. На шаге бронирования их забирает карта решений (`/wayfinder`), после этого файл можно удалить.

## Бронирование

- Параметры расписания для спецификации: начало окна записи (сегодня или завтра), часовой пояс владельца, рабочие часы, шаг стартов слотов, допустимые длительности типов встреч. Предложения по умолчанию — в `STEP-ONE-RESULT.md`, раздел 7.
- Какие данные гостя обязательны при бронировании (предложение: имя и email).
- Нужны ли E2E-тесты в браузере (например, Playwright) для полного пути гостя: каталог → слот → бронирование.

## Владелец

- Нужен ли профиль владельца (имя, описание), который видит гость, и где он задаётся.
- Как владелец попадает в свои разделы: ссылка в шапке или только прямой адрес.

## Деплой

- Раздача фронтенда в облаке должна отвечать `index.html` на любой путь (ADR 0002), иначе прямой заход на `/book` даст 404.
