# Запись на звонок

Сервис, где один заранее заданный владелец публикует типы встреч, а гости без регистрации бронируют свободное время.

## Участники

**Владелец**:
Единственный человек, чьё время бронируют. Задан заранее, заводит типы встреч и видит бронирования.
_Avoid_: хост, организатор, админ, пользователь

**Гость**:
Человек, который без регистрации выбирает тип встречи и бронирует слот.
_Avoid_: клиент, пользователь, посетитель

## Встречи и время

**Тип встречи**:
Шаблон встречи владельца с названием, описанием и длительностью.
_Avoid_: услуга, событие, event type

**Слот**:
Свободный промежуток времени длительностью в тип встречи, который гость может забронировать.
_Avoid_: окно, интервал, время

**Бронирование**:
Слот, занятый гостем под конкретный тип встречи. Бронирования не пересекаются, даже у разных типов встреч.
_Avoid_: запись, встреча, заказ, booking. «Записаться» допустимо только как глагол в текстах интерфейса.

**Окно записи**:
Ближайшие 14 календарных дней, в пределах которых гость может забронировать слот; сдвигается вместе с текущей датой.
_Avoid_: период, горизонт

## Страницы

**Главная страница**:
Страница для гостя, которая объясняет сервис и ведёт в каталог типов встреч.
_Avoid_: лендинг, стартовая

**Каталог типов встреч**:
Страница, где гость выбирает тип встречи; точка входа в бронирование.
_Avoid_: страница записи, список услуг, страница бронирования
