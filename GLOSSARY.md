# Запись на звонок

Сервис, где один заранее заданный владелец публикует типы встреч, а гости без регистрации бронируют свободное время.

## Участники

**Владелец**:
Единственный человек, чьё время бронируют. Задан заранее, заводит типы встреч и видит бронирования.
_Avoid_: хост, организатор, админ, пользователь

**Гость**:
Человек, который без регистрации выбирает тип встречи и бронирует слот.
_Avoid_: клиент, пользователь, посетитель

## Встречи и время

**Тип встречи**:
Шаблон встречи владельца с названием, описанием и длительностью.
_Avoid_: услуга, событие, event type

**Слот**:
Свободный промежуток времени длительностью в тип встречи, который гость может забронировать.
_Avoid_: окно, интервал, время

**Бронирование**:
Слот, занятый гостем под конкретный тип встречи. Бронирования не пересекаются, даже у разных типов встреч.
_Avoid_: запись, встреча, заказ, booking. «Записаться» допустимо только как глагол в текстах интерфейса.

**Предстоящее бронирование**:
Бронирование, которое ещё не закончилось, включая уже идущее. Владелец видит только предстоящие бронирования.
_Avoid_: будущая встреча, активная запись, upcoming

**Конфликт**:
Отказ в бронировании, потому что время пересекается с уже существующим бронированием. Встреча может начаться ровно в момент окончания другой.
_Avoid_: двойное бронирование, занятость, overlap

**Окно записи**:
Сегодня и 13 следующих календарных дней по времени владельца: в эти дни гость может забронировать слот. Окно сдвигается вместе с текущей датой.
_Avoid_: период, горизонт

**Время владельца**:
Часовой пояс владельца; по нему считаются даты окна записи, рабочие часы и всё время, которое видит гость.
_Avoid_: местное время, время сервера, UTC

**Рабочие часы**:
Дни и часы, в которые владелец принимает встречи; слот целиком лежит внутри них.
_Avoid_: расписание, доступность, availability

## Страницы

**Главная страница**:
Страница для гостя, которая объясняет сервис и ведёт в каталог типов встреч.
_Avoid_: лендинг, стартовая

**Каталог типов встреч**:
Страница, где гость выбирает тип встречи; точка входа в бронирование.
_Avoid_: страница записи, список услуг, страница бронирования

**Страница типа встречи**:
Страница, где гость выбирает день и слот выбранного типа встречи, оставляет имя и email и получает подтверждение бронирования.
_Avoid_: страница бронирования, календарь, страница записи

**Разделы владельца**:
Страницы, где владелец видит бронирования и заводит типы встреч; открыты без входа.
_Avoid_: админка, кабинет, личный кабинет
